# CPASv2 Data Collection

Follow these steps to download and prepare the data required to run the
CPAS algorithm to create travel time maps to destinations. This assumes
that you already have the costs files (both landcover and road) and
destinations file.

1.  If you don't have one, create an account with Google Earth Engine
    and create a project
    (<https://code.earthengine.google.com/register>)

2.  Download the Global Land Cover Classification Map here:
    <https://zenodo.org/records/3518026>

3.  Download the following files from the Humanitarian Data Exchange
    ([Humanitarian Data Exchange \| Find & Use Crisis Data \|
    HDX](https://data.humdata.org/)):

    a.  Roads shapefile: Look for HOTOSM roads. For example, for
        Nigeria, search for "Nigeria Roads" and choose the
        "OpenStreetMap Export" option, uploaded by the Humanitarian
        OpenStreetMap Team (HOT). Download the file with "\_lines_shp"

    b.  Country Boundary: Search for "Nigeria administrative
        boundaries". Choose the OCHA ones if available, download the
        file with "adm0"

Once these are set up, edit the DataCollectionConfig.yml file to add the
paths to these files, and the required output path files. The comments
in the configuration file should be self-explanatory.

After the DataCollectionConfig file has been properly set up, you can
run the CPASv2DataCollection.py script, passing the configuration to it
with the command "python CPASv2DataCollection.py
DataCollectionConfig.yml"

This script will now (assuming all the parameters have been set to True
in the configuration):

- Create a subset of the destinations file (for the relevant region of
  interest) and save it as a shapefile

- Create a version of the roads shapefile that can be used by the CPAS
  codebase

- Shows if there are any new road types that need to be considered

- Creates a road costs subset containing only the road types present in
  the region of interest

- Crops the Land Cover map to region of interest

- Generates an SRTM DEM map request in the defined Google Earth Engine
  project

  - You will need to go to your Google Earth Engine console and download
    this file to your Google Drive first, and then to your work
    directory -- unfortunately I haven't found a way to make this easier

- Creates configuration files to run CPAS code

The first step of the above may not be relevant if your initial
destinations file is already specific to a country/region -- in that
case, simply set the "Health" option to False in the Config.

# CPASv2 Code  {#cpasv2-code}

Follow the README instructions in the CPAS repository to set up the CPAS
codebase. The instructions to run CPAS is also given there, use the
configuration files generated by the above step as input.
